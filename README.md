# Emerald Data Engineering Portfolio

A black + emerald green personal portfolio starter built with Next.js, TypeScript, Framer Motion and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## First edits

Search `app/page.tsx` for:
- `[Your Name]`
- `your.email@example.com`
- `yourusername`
- Project descriptions and skills
- Education and certification details
- Short-film placeholder

Add your resume as `public/resume.pdf`.

## Before publishing

Replace every placeholder with accurate information. Remove tools you cannot confidently discuss. Add real GitHub repository links and a real short-film poster/trailer if you want to show one.

## Deploy

Push the repository to GitHub, import it into Vercel, and deploy with the default Next.js settings.
